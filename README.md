# 📊 E-Commerce Sales Analytics and Forecasting

## 📌 Project Overview

This project analyzes the Brazilian Olist E-Commerce dataset to uncover sales trends, customer purchasing behavior, and business insights. A Linear Regression model is used to forecast future sales, while Power BI dashboards provide interactive visualizations for decision-making.

---

## 🎯 Objectives

- Analyze historical sales performance
- Identify monthly and yearly sales trends
- Understand customer purchasing behavior
- Visualize KPIs using Power BI
- Forecast future sales using Machine Learning
